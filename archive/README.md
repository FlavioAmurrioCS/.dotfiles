# Archive

Old configs kept for reference after a rewrite or a move. mise never links
these files into `~`.

- Files keep their path relative to `~`: `~/.tmux.conf` is `.tmux.conf` here.
- Files are kept exactly as they were, with no Location header.
- If a path is archived again, add the date: `.tmux.conf.2027-03-01`.
- Also add the date when the original name would be live inside this repo,
  such as `.gitignore`, `.gitattributes` or `mise.toml`.

| File          | Original path   | Archived   | Replaced by                    |
| ------------- | --------------- | ---------- | ------------------------------ |
| `.tmux.conf`  | `~/.tmux.conf`  | 2026-10-25 | `.config/tmux/tmux.conf`       |
